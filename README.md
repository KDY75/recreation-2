# 비공개 소입자 관측전 · 운영 콘솔

24인 팀 추리 게임을 진행자 한 명이 빠르게 운영할 수 있도록 만든 전용 프로그램입니다.

## 실행

프로젝트 폴더의 `게임운영프로그램_실행.cmd`를 더블클릭하면 프로그램과 브라우저가 열립니다.

현재 Codex 작업 중에는 `http://localhost:3000/`에서도 바로 확인할 수 있습니다.

공개 배포 후에는 모든 운영자가 같은 주소로 접속하면 됩니다. 각 노트북의 브라우저가 하나의 독립 게임방으로 동작합니다.

운영 화면은 비밀번호로 잠겨 있으며, 전체 정답표는 암호화된 상태로만 저장소에 포함됩니다. 비밀번호는 저장소에 기록하지 않고 운영자에게 별도로 전달합니다.

## 포함 기능

- 운영자 비밀번호와 암호화된 전체 정답표
- 노트북별 독립 게임 진행과 자동 저장
- S·K·P팀 24명의 고정 입자·상태 배정표 저장 및 시작 전 편집
- 시작 정보 카드 #001~#003 발급
- 라운드별 충돌 참가자 터치 선택과 입자·상태 분포 자동 판정
- 팀별 비교관측·자기가설 4개 일괄 판정과 카드 자동 발급
- 보정법칙 카드 순차 발급
- 카드 번호 기반 교섭, 사용 카드 잠금, 양 팀 +1점
- 논문 4편 일괄 채점, 동시 최초 발표 및 같은 팀 재발표 처리
- 실시간 점수판과 자동 저장
- 팀별 24인 최종 지도 채점 및 18점 상한
- 전체 공식 데이터 카드 원장과 팀·종류 필터

## 점수 판정

- 최초 발표: +3점
- 정답: +2점
- 같은 팀 재발표: +1점
- 오답: -1점
- 같은 라운드에서 다른 팀이 같은 참가자를 맞히면 모두 최초 발표로 인정
- 최종 지도: 완전 일치 1명당 +1점, 최대 18점

게임 상태는 사용하는 노트북의 브라우저에 자동으로 기록됩니다. 같은 사이트에 접속해도 다른 노트북의 기록과 섞이지 않습니다. 새 게임을 시작할 때는 상단의 `새 게임 초기화`를 사용하면 배정표는 유지되고 그 노트북의 진행 기록만 초기화됩니다.

브라우저의 사이트 데이터를 삭제하거나 시크릿 모드를 사용하면 저장 기록이 사라질 수 있으므로, 게임 중에는 같은 노트북과 같은 브라우저를 계속 사용하세요.

비밀번호 인증은 현재 브라우저 탭이 열려 있는 동안 유지됩니다. 탭을 완전히 닫았다가 다시 열면 운영자 비밀번호를 다시 입력해야 합니다.

## GitHub Pages 배포

이 저장소에는 `.github/workflows/deploy-pages.yml`이 포함되어 있습니다. GitHub 저장소에 올린 뒤 저장소의 `Settings → Pages → Source`를 `GitHub Actions`로 선택하면 이후 `main` 브랜치에 변경사항을 올릴 때 자동으로 다시 배포됩니다.

배포용 파일만 직접 확인하려면 아래 명령을 실행합니다.

```powershell
npm run build:pages
```

완성된 정적 파일은 `github-pages-dist` 폴더에 생성됩니다.
